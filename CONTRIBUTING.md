# Contributing

Keep Orpheus small. Prefer Codex's native research and collaboration capabilities and focused Skills over new orchestration frameworks.

Use a separate source checkout, run the tests described in the README, and describe what changed and how it was validated. Test Fact operations with temporary repositories and synthetic data. Do not include a real research project's notes, Fact records, candidate IDs, credentials, logs or absolute local paths in issues or pull requests.

Preserve the admission path: immutable candidate, independent cold review, bound verdict and explicit acceptance. Do not add silent edits to accepted proofs, automatic destructive recovery, or a model agreement shortcut.

Markdown should remain UTF-8 and Obsidian compatible. User documentation uses `$...$` and `$$...$$` formula environments. Keep new instructions scoped and concise.

Report security or privacy concerns using a minimal, redacted reproduction. Do not publish credentials or private research as evidence. This project does not currently advertise a dedicated private security reporting channel.
