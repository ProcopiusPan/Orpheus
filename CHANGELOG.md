# Changelog

## 0.1.3 — 2026-10-25

- Read closely related original papers, reconstruct their motivations and proof mechanisms, and combine them with current results for generalization, strengthening and unification.
- Treat similarities as opportunities to learn and develop a route; distinguish an already-known claim from the value of the wider research direction.
- Add selective structural-thinking guidance for actual comparisons, proof compression, sufficient weakening, obstructions, invariants and finite determination.
- Clarify contribution priorities without making originality a prerequisite for exploration or Fact admission.
- Document Fact search substring semantics and maintain one current research entry with reusable literature and method notes.
- Keep the Fact service, independent review protocol and installer behavior unchanged.

## 0.1.2 — 2026-10-19

- Organize literature in existing Zotero collections during research and writing, with classifications adjustable as reading progresses.
- Reuse remembered Zotero 10+ local API authorizations across conversations through Windows Credential Manager, scoped to each Zotero instance.
- Add a shared local API helper with bounded authorization renewal, concurrent authorization coordination, and synthetic credential-flow tests.
- Update literature-management guidance and usage instructions.

## 0.1.1 — 2026-10-18

- Generalize paper-writing instructions and examples across mathematical fields, with manuscript structure and synchronization determined by each project.
- Bundle the Fact-based paper-writing Skill, evidence and incremental-update guidance, manuscript validation, and readability polishing, with usage instructions.
- Search prior work at the start of every new problem and when new structures or mechanisms emerge, including alternate terminology and reusable theories across fields.
- Compare applicability, required bridges and the remaining contribution; retain search scope in existing notes for efficient resumption.

## 0.1.0 — 2026-10-11

First public source release.

- Codex-led research with optional native collaborators and user-selected models.
- Useful local theorem extraction, feasibility probes and research-route comparison.
- Fresh independent candidate review with explicit direction, sign, degree and shift checks.
- Git-backed Fact admission, exact dependencies, invalidation, integrity checks and explicit recovery.
- Persistent Obsidian notes and literature records, optional Zotero registration, and bound computation artifacts.
- Windows installer, pinned Python dependencies, synthetic tests and an empty-data release package.

Validation records cover software and installation checks. They do not establish mathematical correctness, model research performance or remote repository protection.
