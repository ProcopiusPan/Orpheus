# Fact 驱动的论文写作

先从目标项目的约定和现有稿件确定读者、活动源文件与本次范围。分析或评估请求只读，写稿或修订请求更新指定稿件及受影响的配套文件。

新稿和增补都先按精确 Fact ID 和版本核对接纳状态、承重的直接依赖及其适用假设；使用计算结果时读取该版本绑定的报告和附件。[证据读取与增量更新](references/evidence-and-updates.md)

## 把结果写进论文

- **新稿**　已有项目或期刊模板时沿用其版式。其余 LaTeX 稿件按是否分章选用[无章论文](assets/article/main.tex)或[分章长稿](assets/monograph/main.tex)，将所选目录完整复制到目标项目，替换示例正文和书目。在副本中运行 `latexmk -pdf main.tex`。围绕中心问题安排定义、定理、证明与算例。几条 Fact 可以合成一个论证，承重步骤在正文展开。
- **增补**　用精确版本和状态核对哪些断言新增、被替代或已补齐；从最早受影响的段落改起，同步相关摘要、引用及现有结果对照。未闭合的桥接保留为待证问题。
- **精修**　初稿和增补完成后，检查段落是否解释了数学问题、关键选择及结果的意义。用户只要求润色时，保留原有数学内容与强度。[写作后可读性精修](references/readability-polish.md)

写作只读研究证据。按完整命题、假设、证明、原文位置及绑定计算材料确定断言的范围。保留原命题的量词、适用范围和推论方向。例如，证明了存在性时，构造方法或唯一性仍需各自的依据。计算例子写明输入与输出，区分一般算法证明、实现范围和单次运行。需要复算时从精确附件复制到独立运行目录。

项目已有文献管理授权时，可随写作登记和归类实际使用的文献。[文献归类](../../references/literature-management.md)

交付时说明稿件改动、已做的检查及影响结论的未决处。LaTeX、PDF 及多版本稿件按目标项目约定同步验证。[稿件同步与验证](references/manuscript-validation.md)
