# 文献探索与分析

文献阅读用于吸收前人的问题意识、结果与方法，帮助当前研究继续发展，并逐步明确贡献。发现相似工作时，优先取得原文，理解其整体贡献与关键论证，考虑怎样与当前结果结合、推广、加强或抽象；相似性本身不否定研究路线或创新性。研究阅读与正式引用核验各有用途：可以广泛探索，进入证明的依据仍须精确核验。

新增、复用和阅读文献时，按[文献归类](literature-management.md)顺手维护 Zotero 集合和项目入口；分类可随理解调整，不另设审批或复核流程。

## 新问题与新结构的主动检索

每个新问题启动时先检索已有工作；研究中发现新结构、等价表述、关键机制或拟独立发展的旁支时，再以新识别的信息检索。检索应影响下一步投入，而不是等长证明或大规模计算结束后再补相关工作。恢复已有问题时读取已有记录，围绕新信息补查，不机械重做相同搜索。

先用项目笔记、Fact 和可用的本地文献复用已知信息，再进行外部检索。把问题的原始术语与结构描述同时作为入口：提取对象的定义、公理、核心运算、方程、不变量、对偶关系及等价表述，查找别名和不同领域的常用名称。除本方向的同名问题外，主动寻找其他数学方向及相关学科中的抽象框架、经典定理和应用实例；不要只在最初命中的作者、术语或分类内循环。

广泛检索先找能改变研究判断的结果和机制，再精读有用原文。除了直接解答，还要寻找包含本问题的更一般结论、可将其化归到已知情形的变换，以及更有效的证明或计算方法。综述、教材和引用链可帮助辨认成熟理论；搜索与引用工具按当前环境选用，不要求固定平台、篇数或额外代理。

结构相似是深入阅读的线索。取得原文后，理解对象、假设、主要结果、构造与证明机制，再比较哪些可以直接吸收，哪些需要桥接，哪些仅提供方法启发；核查迁移时所需结构是否真的保留。主动考虑既有理论与当前结果是否互补，能否削弱假设、加强结论、统一不同情形或提炼一般机制。某个结论确被包含时引用原结果，不把这一局部判断扩大成整条路线无价值；调整总目标范围时向用户说明。

Leader 根据实际阅读持续更新最接近的工作、可吸收的方法及下一步发展机会；已有材料足以支持尝试时即可推进，不要求先查清整个领域或证明创新性。例子、表述澄清与有依据的证明探索可以和文献阅读并行。这不是提交前审计，也不阻止完整的小结论及时冷审入库。网络或原文暂不可用时记录缺口，不以题名或摘要判定完全覆盖；未找到结果也不据此认定原创。用户明确要求复现、独立推导或单条引用核验时按其范围工作。

## 把检索变成覆盖判断

检索的交付是“已有工作怎样帮助本次研究、怎样结合并继续发展”，以及有依据的覆盖比较，不是文献数量或创新性否决。比较时将目标表述为不依赖项目自造术语的数学断言：对象与结构、必要假设、结论强度、适用范围及需要保留的关系。保留真正承重的约定，也不为制造差异而把每个模型细节都当作创新点。

先查内部，再与外部比较：

- **内部已有结论：** 用结论、关键运算、结构别名和一般接口搜索 Fact 索引及问题记录，不只搜当前对象名或完整长句。读取匹配 Fact 的状态、精确版本、命题和适用范围；笔记中的“开放”或一次零命中不足以判定尚未解决。疑似命中只解决一部分时，写出仍缺的那一步。
- **查询工具的边界：** 按[Fact 工具与证据](facts.md)确认检索语义；连续子串检索须拆开关键词调用，不能把空格分隔的整句当成语义搜索。结果截断或零命中时调整术语与定位范围，不据此决定数学上的覆盖状态。
- **外部已知理论：** 除同名结果外，检查能包住目标的更一般定理、等价表述、经典教材和证明机制。找到一个局部引理后，核同篇主定理及相关更强结果，避免长期证明已有全局定理的较弱特例。
- **逐条件比较：** 将已有结果的对象／假设对应到当前对象，逐项核对；再比较结论。若声称保留更多结构、扩大适用范围或加强结论是新增，指出已有定理具体缺少什么，以及该差额为何不能由原定理或其直接推论得到。用词不同和模型不同本身不构成数学差额。

在已有 `文献与证据.md` 中保留可复用的比较，`问题与进展.md` 只留简短结论和行动。可按实际情况使用下面的判断，不需要新增表单或机器状态：

| 覆盖判断 | 对下一行动的影响 |
| --- | --- |
| 发现结构、对象或方法相似 | 深入原文，吸收结果与思路，寻找与当前结果的互补和发展机会；不据相似性否定路线 |
| 某个断言被已有 Fact 或外部定理直接覆盖 | 复用并将该断言改记为已知，结合当前结果考察推广、加强、统一或新证明；需要时登记文献 Fact |
| 某个断言由已有定理直接推出 | 核对代入并定位为推论／应用，可作为后续发展的基础，不包装成独立机制 |
| 需要实际桥接或只有部分覆盖 | 复用已建立的部分，探索对应关系与组合方式，继续推进整体目标，不将整条路线限制为一条接口修补 |
| 有具体的发展方向 | 结合原文与当前结果尝试推广、加强或方法改进，随进展明确贡献，不要求事前取得原创性结论 |
| 覆盖未判定 | 记录待核原文和条件，有依据的探索可并行；暂不作肯定或否定的创新性结论 |

只有实际核过命题和条件的结果才能支持直接覆盖或直接推出的判断；题名相似不能宣布已覆盖。反过来，自足证明或没有正式 `sources` 也不能免除研究路线的已有工作比较。结论覆盖与证明方法的覆盖分别判断：若目标是新方法或有独立价值的新证明，比较已有证明的机制与预期新收益，不因结论已知就关闭；常规重证仍只作复用。用户指定复现或独立推导时，允许重证，但明确标注，避免计作新的研究贡献。

同一比较和阅读认识可供连续的小候选复用，修补证明不自动触发全新一轮检索。新的相关工作出现时，及时向 Leader 报告可吸收的工具、对已有理解的修正以及结合发展的机会。核实直接包含的断言改记为已知，避免无目的重证；不要仅因新先例相似就停止整条研究链。已接纳的正确 Fact 保留，贡献定位在笔记中随认识更新。

## 从有用结果扩展阅读

围绕当前问题先浏览同篇论文的引言、主要结果陈述、相关章节和结论，梳理整体贡献和结果关系。特别检查当前引用是否为更强定理的特例，是否还有能推进后续步骤的结果，以及证明方法、反例、限制或开放问题是否改变研究路线。相关结果涉及附录时也检查其陈述与适用条件。

“更强”需要比较完整的假设和结论。记录对象、定义、量词、参数范围、正则性和结论形式；假设更强或对象不同的定理未必能替代现有依据。区分“可直接适用”“还需证明桥接条件”和“仅有方法启发”。选定实际采用的结果后深入阅读有关证明和依赖，逐项核对其适用条件。

沿能改变当前路线的前置工作、后续推广、修正和相关引用继续检索，不只沿最初命中的关键词重复搜索。搜索摘要、引用次数和论文自述用于发现线索，不能代替原文核查；比较论文版本，保留勘误或撤回等影响结论的记录。

发现可解释本项目现象、可提炼为独立定理或有其他明确用途的方法时，也向 Leader 报告；它不必推进原总目标。按[研究策略与定理提炼](research-strategy.md)比较最接近的已有结果、可能的自然表述、用途与所需桥梁，区分原创、经典应用和显式化。

贡献定位按同一策略优先辨认新语言、方法或有实质收益的跨领域证明，再辨认旧方法下的新结果和有独立价值的新证明。指出改变了解题方式的具体步骤，以及最接近的已有方法；没有新增方法的直接推论或特殊情形只记为复用／技术支撑，不因另写证明或换一个应用对象而推荐为独立研究成果。非平凡应用桥梁的贡献落在实际新增部分。

已接纳文献 Fact 可以复用同一已核验结论，但它不证明整篇论文已覆盖，也不限制探索该论文的其他结果。新结果超出 Fact 的范围时，另行核对其原文与条件。

## 研究动机与方法重建

理解关键论文或综合一条研究路线时，Reader 不只摘录结论和证明步骤，还要提取作者的问题意识与选择理由：原始问题是什么，当时已有方法卡在哪里，为什么引入这些定义、构造或中间目标，关键选择怎样突破困难。按实际材料还原这条思路，不要求每篇文献填写固定表单。

- **定义与构造的动机：** 它捕捉什么现象、解决什么表达或操作障碍；为什么采用这种表述、假设和研究对象。
- **路线与中间目标：** 为什么先做特例、改变问题、引入辅助对象或分解任务；哪些步骤解释了方法为何有效，而不只是最终证明如何排列。
- **反例与失败经验：** 原文提到的障碍、反例或失败尝试如何推动方法形成，哪些限制仍然存在。没有材料时保留未知，不补造发现经历。
- **跨论文综合：** 比较不同工作如何面对同一类困难，辨认共同机制、不同选择及各自适用边界，形成可借鉴的研究思路，而不是逐篇摘要的拼接。

优先核读引言、例子、注释和关键证明；有助于理解选择理由时，再参考相关讲义、综述、早期工作或作者后续解释，记录来源和位置。区分作者明确说明的动机与 Reader 根据论证重建的解释；论文的最终证明顺序不自动等于历史发现过程。

把理解转成当前研究的可用建议：我们面对什么相似困难，哪些条件和结构对应，哪些定义、分解或路线选择值得尝试；迁移还缺什么、哪一步试探最能判断它是否有效。能直接复用时复用，需要新条件或构造时明确差额；方法启发本身不等于已证明的推广。

提取方法时，可按[结构性思考](research-strategy.md#结构性思考与概念整理)辨认作者怎样建立实际比较桥、把例子提升为机制、统一重复计算、弱化过强目标、组织失败或证明有限决定性。只选与当前困难有关的操作，说明它实际解释或简化了什么；再提出所需条件和可判别的试探，不把高级术语或原文已经提出的展望当作新的方法贡献。

这项工作由现有 Reader 或 Leader 按需承担，可与具体证明并行；在新路线、关键障碍或方法理解不足时使用，不要求每次引用、修补证明或小 Fact 提交都重新综述。Reader 及时反馈能改变问题表述、近期目标或路线的认识，Leader 据此选择下一步，不等待完整综述写完。

## 阅读范围与停止条件

先梳理相关结果，再对有用部分深入阅读；不要求每篇命中文献从头到尾逐字通读。当新增阅读不再改变当前目标的适用范围、证明路线、下一步，也未带来具体可检验的独立定理或应用线索时，可以停止扩展，保存有价值的未读线索。抽象的“可能相关”不支持无限检索；有明确独立收益的旁支可单独界定范围。遇到可能直接解决问题、替代当前方法或否定当前前提的结果时，优先继续核查。

用户明确只要求单条引用核验时，遵守该范围，可简记发现的相关线索。冷审 Verifier 仍按固定候选和正式来源核验，不承担全领域综述；扩展阅读不是新的提交或接纳关卡。原文无法取得时标记访问缺口，不把仅浏览摘要写成已读全文，也不因材料不全声称已穷尽已有研究。

一次检索收束后可以开始研究；新结构、新术语或关键机制出现时重新打开相关检索，不把前一轮搜索当作后续路线已被覆盖的证明。

## 持久记录与研究反馈

沿用已有目录，不建立新的研究状态系统，也不为每次搜索另造文档：

- `papers/` 对应文献 `.md` 中记录整体贡献、相关结果及关系、完整假设与 locator、已读和未读范围；有价值的作者动机、方法选择理由及来源也保存在这里，Reader 的重建解释单独标明。书目登记和正文阅读状态分开；有 PDF 或 Zotero 条目不表示已读。
- 问题的 `文献与证据.md` 记录实际检索日期、主要术语及结构别名、检索范围、关键来源和未覆盖线索，保留可用结果、与目标的条件对应、更强替代结果及待核查桥接。记录到足以避免重复检索和复查结论即可，不转录全部搜索输出。
- Leader 在 `问题与进展.md` 更新已有工作覆盖的范围、当前贡献定位、剩余证明义务和下一步；文献改变目标或路线时及时说明原因。贡献定位随检索更新，不把暂未找到同类工作写成确定的原创性结论。

跨论文的方法综合与对当前问题的迁移建议，按需要写入已有 `文献与证据.md` 的“研究动机与方法迁移”部分，链接对应阅读记录，说明可借鉴的选择、尚缺条件和下一步试探。沿用现有笔记，不为每篇论文另建综述报告。

Reader 的交付应回答“已有工作解决了多少、还剩什么、是否改变路线”，并在有依据时指出值得提炼的结构定理或独立用途，而非只返回定理编号。跨论文比较可用简短表格：结果与定位、假设、结论、对本问题的作用、核查状态。按实际有用内容填写，避免空表和固定篇数指标。

广泛阅读笔记是研究材料；正式候选只引用实际核验的结果与精确来源。需要持续复用的结果仍按独立结论提交小 Fact，不把整篇论文或整套相关工作打包成单一 Fact。
